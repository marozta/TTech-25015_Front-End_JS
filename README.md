# Talento Tech #25015 - Front_End_JS

Página E-Commerce "Responsive" para contratacion de viajes cortos por la Argentina.

Para su construcción se utilizó:
        HTML, CSS y Bootstrap.

        La página es "Responsiva" y se realizó con el criterio "mobile first".
        
        Las secciones: destinos, paquetes y servicios, se confeccionaron con FLEXBOX.

        La sección reseñas se realizó utilizando GRID.

        Las barras de navegación del header y del footer, so obtuvieron de BOOTSTRAP y se adapataron a los requerimiento especificos de esta página.

        Para la responsivilidad de utilizaron media queries:
                Media queries: Tablet (≥576px) - @ media(min-width: 576px){}
                Media queries: Desktop (≥992px) - @ media(min-width: 992px){}
                Media queries: Desktop Extra Large (≥1200px) - @ media(min-width: 1200px){}

        La página contiene un formulario para compra de viajes "BOOK", al completarlo y presionar "Agregar al carrito" se genera dinamicamente con javascript un carrito de compras, donde se detallan las caracteristicas del viaje.

        En el carrito de compras al presionar el botón "Confirmar compra" se genera dinamicamente un resumen de la compra y el detalle de la misma se envia a formspree, donde se recepciona para realizar la reserva y proceder al cobro.

        Como funcionalidad agregada, al recibir el resumen de la compra, el usuario tambien puede ver el pronóstico del clima del plazo del viaje (si está dentro del rango pronosticable), el cual se genera consumiendo una API llamada: Open-Meteo (https://open-meteo.com/)

        Además se  recurrió a las páginas:
        Font Awesome, para la obtención de iconos para la decoración de la página.
        Google Fonts, para la utilización de fuentes adicionales.

        Todas las imagenes, tanto fotografias, ilustraciones han sido obtenidas de las páginas: Unsplash - Freepik - Pexels - Pixabay, en todos los casos son gratuitas  y/o libres de derechos.
